# Экспериментальное улучшение качества

В плеере: **Настройки → Улучшение качества**. Поверх настроек открывается модальное окно с режимами:

- **Выключено** — значение по умолчанию, обычный путь воспроизведения.
- **Лёгкий** — Anime4K Upscale DoG x2, четыре прохода.
- **Качественный** — Anime4K Upscale CNN x2 S, пять проходов.

Выбор сохраняется на устройстве. Переключение пересоздаёт плеер с прежней позицией; видео остаётся на паузе, пока открыты настройки. Закрытие модалки возвращает фокус к пункту настроек. Декодирование остаётся аппаратным, дополнительная обработка выполняется на GPU через Media3 Effect.

## Исходники и адаптация

Оригинальные шейдеры bloc97/Anime4K сохранены без изменения алгоритмов (нормализованы пробелы) в `app/src/main/assets/anime4k/`, вместе с MIT-лицензией и уведомлениями об авторских правах:

- https://github.com/bloc97/Anime4K/blob/master/glsl/Upscale/Anime4K_Upscale_DoG_x2.glsl (blob `036411fa6c2e7b57c89c8db9626bc5307f221f56`)
- https://github.com/bloc97/Anime4K/blob/master/glsl/Upscale/Anime4K_Upscale_CNN_x2_S.glsl

Это конкретные алгоритмы v3.2 из репозитория Anime4K, а не полный набор современных mpv-пресетов A/B/C. Адаптер поддерживает только две поставляемые цепочки: зависимости текстур, промежуточные сохранения и увеличение до x2. Пользовательские шейдеры не загружаются.

Промежуточные вычисления используют RGBA16F, чтобы сохранить отрицательные значения CNN. Изображение переводится из линейного BT.709 Media3 в гамма-кодированный RGB и обратно. Обработка ограничена разрешением экрана, 3840×2160 и максимальным размером текстур GPU. Видео без необходимости увеличения не обрабатывается. Фактическое разрешение вывода зависит от размера видеоповерхности и режима Android TV.

## Ограничения и восстановление

Функция экспериментальная: нужны OpenGL ES 3 и поддержка рендеринга в floating-point textures. Предназначена для SDR. HDR не пропускается через SDR-модель. При ошибке инициализации или обработки эффект отключается с уведомлением, плеер восстанавливается на прежней позиции. Сетевые ошибки не изменяют настройку Anime4K.

Автоматическое отключение по частоте кадров не реализовано. Плавность, расход памяти, качество масштабирования и переключение режимов требуют проверки на реальном Android TV. Шейдеры не восстанавливают потерянные детали исходного видео.

## Проверка на телевизоре

1. Открыть настройки во время просмотра. Проверить модалку, выделение сохранённого режима, управление стрелками и возврат по «Назад».
2. Переключить оба режима и выключить. Проверить сохранение позиции, паузы и настройки после перезапуска.
3. Сравнить 720p/1080p на 4K-экране; убедиться, что 4K-источник не увеличивается повторно.
4. Проверить отсутствие текста под нижним рядом кнопок во время паузы и перемотки.
5. На неподдерживаемом GPU/HDR проверить восстановление обычного воспроизведения без цикла повторных ошибок.
