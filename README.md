# AniHall — Android и Android TV

Развитие форка AniLiberty с собственными интерфейсами для телефона и телевизора. YummyTV используется как ориентир по сценариям; в этом этапе его исходники и ресурсы не переносились. Единственный сервис данных и воспроизведения — AniLiberty API v1.

## Первый этап переноса

Один APK содержит две точки входа: обычный Android launcher открывает `mobile.MobileActivity`, Android TV launcher — `MainActivity`. Существующий application ID сохранён, чтобы обновление не удаляло данные.

Общая модель `AppModel`, API, UUID серий, история, расчёт порога просмотра и выбор серии используются обоими интерфейсами. Модели главной и строк представления вынесены из API и большого UI-файла. Новые Gradle-модули и зависимости не добавлены.

Телефон: нижняя навигация «Главная / Каталог / Библиотека», поиск, сетка постеров, продолжение просмотра, расписание на сегодня, жанры, карточка тайтла, локальное избранное, серии и похожие тайтлы. Отдельный сенсорный Media3-плеер поддерживает качество, скорость, выбор серии, автопереход, пропуск опенинга/эндинга и порог просмотренности. Позиция сохраняется при уходе в фон и восстановлении Activity. Переключение качества сохраняет позицию.

ТВ: существующие экраны, авторизация, серверные коллекции и плеер сохранены. «Продолжить просмотр» стоит первым. Быстрый запуск, карточка тайтла и лента используют общий выбор серии: UUID остаётся точным при явном выборе, автоматический выбор учитывает порог просмотра и пропускает недоступные потоки. Повторные нажатия во время запроса не открывают несколько плееров.

Это первый этап, а не завершённая визуальная копия YummyTV. На телефоне ещё нет экрана входа, управления серверными коллекциями, загрузок и PiP. Библиотека телефона пока локальная. Визуальное соответствие, крупный системный шрифт и поведение на реальных устройствах требуют отдельной проверки.

## Проверки и сборка

```shell
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

Требуются JDK 17 и Android SDK 36. APK: `app/build/outputs/apk/debug/app-debug.apk`. CI включён для `rewrite/tv-next` и `feature/anihall-yummytv-structure`; артефакт — `AniHall-Android-debug`.

Новые проверки покрывают порядок полок главной, сохранение ключей фокуса, точный UUID запуска, недоступные серии, блокировки и порог просмотра. Результаты и ограничения среды — в [журнале этапа](docs/ANIHALL-STAGE-1.md).
