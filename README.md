# AniLiberty TV Next

Новый Android TV клиент в ветке `rewrite/tv-next`. Это отдельная кодовая база с нуля: один модуль `app`, без старого `app-tv`, Leanback, Quill, старых моделей и PHP API. Из предыдущего проекта сохранены только лицензия и Gradle Wrapper.

Визуальный источник — страница релиза AniLiberty из предоставленного HTML-архива. Навигация рассчитана на пульт: стрелки выбирают вкладку, OK / ↓ переносят в содержимое, ↑ из первого ряда возвращает к вкладкам. Заголовки не получают фокус.

Главная: промо и горизонтальные полки новых эпизодов, расписания, франшиз, жанров и видео. В новых эпизодах, расписании и видео — до девяти элементов и стрелка «Все». В жанрах — четыре случайные карточки, во франшизах — три, «Обновить» и «Открыть все»; обновление касается только выбранной подборки. Жанры и франшизы выбираются случайно и сохраняются при возврате. Постеры с читаемыми подписями под изображением; широкие карточки для остальных типов. Торренты доступны только через «Ещё» в релизе, загружаются по запросу. Статические Montserrat SemiBold 600 / Inter Regular 400, лицензии — docs/fonts.

Первая рабочая сборка: стартовый экран, последние обновления, каталог с поиском и страницами, тайтл, эпизоды с превью и длительностью, команда, Media3 HLS-плеер с выбором качества и серии. Прогресс сохраняется по UUID эпизода. Локальная библиотека не связана с серверным избранным.

Это начальный этап новой реализации, не завершённая замена всех функций. Серверная авторизация, коллекции и синхронизация ещё не реализованы. Франшизы и рекомендации AniLiberty показаны нативно в карточке; обсуждение пока открывается на сайте. Shikimori/MAL ID и рейтинги из AniLiberty сохраняются раздельно. Внешние каталоги пока не подключены. Автопереход между эпизодами, субтитры и пропуск опенинга ещё предстоят.

## Сборка

JDK 17, Android SDK 36:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

Пакет `tv.aniliberty.next`, APK `app/build/outputs/apk/debug/app-debug.apk`. Устанавливается рядом с предыдущим приложением. Данные предыдущего клиента не мигрируются и не удаляются.

В плеере кнопка MENU открывает выбор серии и качества. Экранные контролы скрываются через 3 секунды. Недоступные HLS-потоки не подменяются внешними источниками.
