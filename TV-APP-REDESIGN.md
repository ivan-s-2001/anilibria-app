# AniLiberty TV: приложение целиком

## Задача

Перепроектируем клиент Android TV с первого запуска. Карточка тайтла — один из экранов.
Сохраняем рабочие авторизацию, сетевые адаптеры, репозитории и Media3. Серверный контракт
не меняем. Новый сервер, источники контента и переход на API V1 не входят в эту работу.

Основное действие: выбрать аниме и начать или продолжить просмотр с пульта.
Контекст: realme Android 11 и Xiaomi Android 14, чтение с дивана, ограниченная память.
Крупные постеры, кириллица, предсказуемый фокус и Back важнее плотности каталога.

## Единая система

Новая ресурсная база: res/values/tv_design_system.xml. Нейтральный тёмный фон,
светлый текст, приглушённый вторичный текст, белый фокус. Размеры в dp, текст в sp.
Основные поля 48 dp, расстояние между колонками 48 dp, между действиями 12 dp.
Кириллица — системный sans-serif. Display 36 sp, заголовок 26 sp, текст 16 sp,
подписи 13 sp. Цвет несут постеры; не окрашиваем фон целиком цветом постера.

| Компонент | Роль | Обязательное поведение |
|---|---|---|
| TvChoice | Выбор способа входа и действия с пояснением | Один focus target на весь блок, светлый фон и тёмный текст в фокусе |
| PrimaryAction | Смотреть / Продолжить / Подтвердить | Название объясняет результат; защита от повторного действия при загрузке |
| SecondaryAction | Серии / Фильтры / Сортировка | Открытие панели с возвратом фокуса на кнопку |
| PosterCard | Выбор релиза | Постер 150×214 dp, название, одно краткое уточнение; стабильная высота |
| ContinueCard | Возобновление | Последняя доступная серия/позиция, прямой запуск; подробности доступны из библиотеки |
| StatusMessage | Пусто / ошибка / недоступно | Причина и доступное следующее действие |
| Field | Логин / пароль / код | Постоянная подпись, пароль скрыт, ошибка рядом с формой |
| SelectionPanel | Серии / фильтры / качество | Текущий выбор виден; Back закрывает только панель |
| FocusFrame | Навигация по постерам | Декоративный, не фокусируемый; без скачков высоты и циклической idle-анимации |
| AppShell | Разделы, контекст возврата | ID выбранного элемента и позиция; данные не перехватывают фокус |

Сначала внедрены TvChoice и стартовый экран. Ресурсы старых экранов ещё не переведены
целиком на новую систему; наличие таблицы не означает готовность всех компонентов.

## Карта экранов и критерии готовности

| Экран | Задача | Основные блоки | Проверка |
|---|---|---|---|
| Подготовка сервиса | Открыть приложение | Состояние подключения, повтор | Недоступность сервиса не оставляет бесконечный spinner |
| Первый запуск | Выбрать путь | Вход по коду, логин/пароль, гостевой просмотр | Первый фокус на коде; все пути доступны пультом |
| Вход по коду | Авторизоваться с телефона | Код, инструкция сервиса, подтверждение, истёкший код/повтор | Back возвращает к выбору; ошибка не стирает инструкцию |
| Логин и пароль | Войти на ТВ | Подписи полей, скрытый пароль, необязательный 2FA, ошибка | Отмена/ошибка сохраняет контекст, секреты не журналируются |
| Главная | Выбрать просмотр | Продолжение, актуальное, расписание | Пустое продолжение скрывается; навигация между рядами стабильна |
| Каталог | Найти по условиям | Крупная сетка, сортировка, фильтры, сводка | Последний фильтр побеждает при медленной сети |
| Поиск | Найти по названию | Ввод, минимум символов, результаты, ошибка | Работает без голосовых сервисов |
| Моё | Вернуться к своему | Продолжение, история, избранное | Локальная история и аккаунтное избранное различаются |
| Карточка | Решить, смотреть ли | Большой постер, информация, описание, основное действие | Доступность действий соответствует данным |
| Серии / части | Выбрать эпизод | Группы сервиса, текущий эпизод и позиция | Открывается на текущем эпизоде; без выдуманных сезонов |
| Плеер | Смотреть | Видео, прогресс, пауза, серия, качество, скорость, skips | Позиция и скорость сохраняются, ошибка допускает повтор |
| Профиль | Управлять аккаунтом | Текущий пользователь, вход, выход | Выход не стирает локальную историю |
| Настройки | Управлять клиентом | Реально поддержанные параметры воспроизведения и интерфейса | Не показываем неработающие настройки |
| Обновление | Поставить новую версию | Версия, источник, состояние загрузки/ошибки | Пользователь может вернуться в приложение |

Для каждого экрана: loading/content/empty/error/partial там, где эти состояния имеют смысл.
Пустой список не выдаём за сетевую ошибку. При пагинации оставляем уже загруженный контент.
Текстовое поле не заменяем placeholder. Иконка без текста имеет contentDescription.

## Первый запуск: реализация этой итерации

- WelcomeScreen / WelcomeFragment — отдельный экран приложения, а не карточка тайтла.
- NO_AUTH после подготовки сервиса ведёт в WelcomeScreen.
- AUTH и ранее выбранный AUTH_SKIPPED открывают главную без повторного приветствия.
- Код и логин открывают существующие guided-формы; их внутреннее оформление пока прежнее.
- Успешный вход переводит в главную, гостевой путь сохраняет существующий authSkipped.
- Кнопка входа в профиле тоже ведёт в WelcomeScreen. Данные/пароли не копируются
  в новое хранилище. Если пользователь уже авторизован, приветствие возвращает его в главную.

## Дальнейшая реализация по зависимостям

1. Завершить общие формы: код, срок, ошибки, логин/пароль/2FA, возврат после успеха/отмены.
2. Собрать AppShell и устойчивое восстановление контекста. Убрать разницу между
   отдельными меню/панелями, не переносить legacy focus-хак в новую оболочку.
3. Главная, каталог, поиск, Моё через общие PosterCard/StatusMessage/SelectionPanel.
4. Карточка и список серий через те же компоненты и правила фокуса.
5. Органы управления плеером и настройки. Media3 и рабочие источники сохраняются.
6. Проверка всего пути на двух ТВ и аудит регрессий общего data-модуля.

Каждый этап публикуется сборкой, а не обещанием завершить остальные экраны. Текущая ветка
остаётся рабочей; изменения на сервере и удаление пользовательских данных не требуются.

## Приёмка первой итерации

На чистой установке проверить код, логин, гостя, Back и недоступность сервиса.
На существующей гостевой установке открыть Профиль → Войти в аккаунт и проверить новый
стартовый экран. После отмены кода вернуться в него. После ошибки гостевого перехода
должны остаться действие повтора и видимое сообщение. После входа/пропуска перезапустить
приложение: приветствие не должно появляться снова. Проверить TalkBack и длинные строки.
Сборка GitHub Actions подтверждает компиляцию, но не заменяет проверку пультом на ТВ.
